# Paul Onsongo — Portfolio Website

A responsive static portfolio built with HTML, CSS, and vanilla JavaScript.

## Run locally
1. Extract the ZIP.
2. Open the extracted `paul_onsongo_portfolio_updated` folder in VS Code.
3. Open `index.html` in a browser, or use the VS Code Live Server extension.

## CV
The PDF CV is included at `assets/Paul-Onsongo-CV.pdf`. The website's Download my CV links point to this file.

## Publish for free with GitHub Pages
1. Create a GitHub repository (for example, `paul-onsongo-portfolio`).
2. Upload the contents of this folder to the repository root.
3. Open the repository's Settings → Pages.
4. Under Build and deployment, choose Deploy from a branch, select `main` and `/ (root)`, then Save.
5. GitHub will provide the public website URL after deployment.

## Before publishing
- Review the wording and confirm that every detail is accurate.
- Add your LinkedIn and GitHub links when you are ready; they are intentionally not guessed or invented.
